تصدير وتشغيل تطبيق القرآن (APK)

تم إعداد بنية أندرويد الكاملة (AndroidManifest، build.gradle، MainActivity) وملف البناء التلقائي GitHub Actions في المشروع!

1
البناء المباشر عبر أمر Flutter (إذا كان متوفراً بجهازك): flutter build apk --release

سيتم توليد ملف APK مباشرة في مسار build/app/outputs/flutter-apk/app-release.apk.

2
البناء السحابي التلقائي المجاني (CI/CD):

تم تضمين مسار .github/workflows/build_apk.yml. بمجرد رفع المشروع إلى GitHub، تقوم خوادم GitHub ببناء ملف APK وتوفير رابط تحميل مباشر ومجاني!

3
التجربة الفورية الآن:

يمكنك تجربة كامل خصائص التطبيق (الصوت المباشر من EveryAyah، التكرار N x M، شجرة القرآن، مسابقة الفقاعات، وتوزيع الصلوات) في هذا المحاكي التفاعلي مباشرة!
